# Distributor ROI & Profitability Dashboard

## Project Overview
An Excel-based dashboard project designed to analyze distributor sales, profitability, scheme claims, operating costs, and return on investment (ROI).

**Important:** This project uses simulated sample data for portfolio demonstration. It does not represent actual company results.

## Objectives
- Track primary and secondary sales.
- Analyze distributor profitability and annualised ROI.
- Monitor scheme claims raised versus settled.
- Identify distributors below the 6% profitability benchmark.
- Support business decisions through data visualization.

## Tools Used
- Microsoft Excel
- Excel formulas and tables
- Conditional formatting
- Charts and data visualization

## Key Metrics
- Total primary sales
- Average profitability
- Average annualised ROI
- Claim settlement percentage
- Primary versus secondary sales gap

## Business Recommendations
The analysis can help identify distributors requiring a review of operating costs, sales gaps, and scheme claim settlement.
